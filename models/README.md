# YOLOX Models

This directory contains pre-trained YOLOX ONNX models.

## Downloaded Models

- yolox-s.onnx

## Model Information

- **Input**: 640x640 RGB image
- **Output**: Bounding boxes, class labels, confidence scores
- **Classes**: 80 COCO classes (person = class 0)

## Additional Models

To download other models, modify this script or visit:
https://github.com/Megvii-BaseDetection/YOLOX/releases

- Models are excluded from git (see `.gitignore`)
